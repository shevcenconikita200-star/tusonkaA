Учёт тушёнки — проект Android APK

В проект включена текущая версия программы. После сборки APK устанавливается на Android как обычное приложение, данные хранятся локально в приложении.

Как получить APK через GitHub с телефона:
1. Создайте новый репозиторий на github.com и загрузите туда содержимое этой папки (распакуйте ZIP; загружайте файлы и папку .github тоже).
2. Откройте вкладку Actions в репозитории.
3. Выберите workflow “Build Android APK” и нажмите Run workflow. Если вкладка Actions выключена, включите её.
4. Дождитесь зелёной галочки у запуска, откройте его и внизу раздел Artifacts скачайте tushenka-apk.
5. Распакуйте скачанный архив и откройте app-debug.apk на телефоне. При запросе Android разрешите установку из этого источника.

Это исходный проект с автоматической сборкой, не готовый APK: для создания APK требуется Android SDK, которого нет в текущей среде.
