Сообщения

Настройте отдельный шаблон для каждого чата. Каждое вхождение {message} заменяется полным текстом отправленного сообщения.

Для точного размещения добавьте в шаблон маркер {time} и/или {date}. Например: «Получено в {time}, дата {date}. Текст: {message}». Если выбран режим «В месте специального маркера», время и дата вставляются только в указанные места.

Допустимая задержка: от 0 до 60000 мс. Можно удалить все маркеры {message} — ответ будет отправлен без вставки исходного сообщения.
